# SOC Investigation Write-Ups

This repository documents hands-on security investigations completed while preparing for a SOC analyst role. The write-ups focus on my investigative process, evidence collection, tool usage, and conclusions.

## Methodology Note

These investigations were completed through hands-on analysis of the provided lab data. When needed, I used external references and AI-assisted guidance to clarify unfamiliar concepts, troubleshoot investigative steps, and improve the organization of my final write-ups. All findings, screenshots, conclusions, and technical claims were verified against the available evidence.
